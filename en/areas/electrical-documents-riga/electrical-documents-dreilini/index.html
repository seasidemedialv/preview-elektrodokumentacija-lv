Below is what the as-built documentation contains, how commercial premises are put into use and what a house builder does.

As-built documentation in a new apartment or commercial project

The typical buildings of Dreiliņi are new apartment building projects, detached houses, supermarkets, warehouses and undeveloped land. In a new build, electrical installation as-built documentation is a set of documents showing how the installation was actually built and tested. LBN 261-15, point 53, lists what is attached to the acceptance statement if the work concerned has been done:

  • a set of construction design drawings and detailed drawings corrected under designer’s supervision, as well as automatic control and switching diagrams;
  • equipment data sheets and material conformity declarations;
  • concealed works acceptance records on the installation of electrical equipment;
  • reports on cable resistance, phase-neutral loop measurements and earthing;
  • a description of how to use the systems and safety instructions.

If an electrical subcontractor has not prepared some of the papers or they have been lost, what is missing can be prepared anew: the installation measured and an as-built diagram drawn from the actual state. In your request, write which documents you already have and which are missing, and attach the electrical part of the design if available.

Concealed works records are drawn up before the works are covered up; they are not recreated afterwards. So as-built documentation is planned during construction, not at the end. More detail: electrical installation as-built documentation.

A shop or warehouse: putting into use step by step

Dreiliņi serves housing, retail, logistics, warehousing and new development. For shop or warehouse premises built or rebuilt under a building permit, the acceptance procedure is this:

  1. Measurements and reports The electrical installation is measured, and reports and an as-built diagram are prepared while the distribution boards are still accessible.
  2. Utility statement The body that issued the technical conditions, for example Sadales tīkls, gives a statement on readiness.
  3. Application in BIS The confirmation that the building is ready for use is approved in BIS by the construction participants, and all documents are submitted.
  4. Acceptance date After receiving all documents, the building authority, in agreement with the applicant, sets an acceptance date no later than 10 working days.

The time limit is set by point 171 of the Building Construction Regulations. The Riga municipality states a service processing time of 10 working days, which can be extended to 4 months under the Administrative Procedure Law. The case of office and retail premises is described on the page putting office premises into use. If a tenant fits out a shop in a building already accepted, the procedure may differ: it depends on whether the work requires construction documents, and that is to be clarified with the building authority before work starts.

Checked 25 November 2026: Building Construction Regulations, point 171 (likumi.lv/ta/id/269164); Riga State City Municipality service description (riga.lv).

A temporary connection for a development building site

Dreiliņi has open areas, busy roads and development building sites. If a building site needs electricity before the permanent connection, Sadales tīkls sets up a temporary connection for a period of up to 24 months, and it requires a valid building permit. Without a building permit this route cannot be used, so check the permit status in BIS before applying. The fee for setting up a temporary connection for a building site is €117.21, or €217.52 if additional installation work is needed, under the Sadales tīkls price list, checked 25 November 2026.

A temporary distribution board on a building site is a location for which LBN 261-15 sets special requirements under standards, and connecting it needs electrician’s work on your side. In your request, write the requested capacity, how long the connection is needed and where on the site the board is planned. The procedure is described in more detail in temporary electricity connection for a building site.

A detached house in Dreiliņi that you build yourself

Alongside the large projects, Dreiliņi also has detached houses. If you are building the house yourself as the owner, the Building Construction Regulations require electrical installation test documentation for putting it into use with the building authority. Unlike a shop, there is no site manager here to collect the papers: you handle them.

Arrange the measurements when the indoor installation is finished but the board still open. If different tradespeople did parts of the work, write in your request who installed what, because the diagram has to reflect everything. Read all about this case on the page electrical installation test documentation for a self-built house. If the house does not yet have a permanent connection, the confirmation you submit to Sadales tīkls on e-st.lv is a different document from the measurement report for the building authority, but the electrician’s work for both can be planned in one go.

Questions about these documents

How soon does the building authority accept a building after the documents are submitted?

For a building built under a building permit, after receiving all documents the building authority, in agreement with the applicant, sets an acceptance date no later than 10 working days (Building Construction Regulations, point 171). The Riga municipality states that the time limit can be extended to 4 months.

What makes up electrical installation as-built documentation?

Corrected drawings, automatic control and switching diagrams, equipment data sheets and conformity declarations, concealed works records, reports on measurements and a description of use, if the work concerned has been done. LBN 261-15, point 53, gives the list. Of these, the measurements are carried out by a certified electrical specialist.

Does a temporary connection need a building permit?

Yes. Sadales tīkls sets up a temporary building site connection for up to 24 months, and it requires a valid building permit. Short events have a separate connection of up to 31 days, applied for at least 10 working days in advance.
