For a new building or a detached house you are starting to build now, the papers begin on the construction site with a temporary connection and end with putting into use. For an old wooden or brick house they begin with the question of what remains of the installation and how to describe it when the design no longer exists.

A self-built detached house: electrical papers for handover

The typical development of Torņakalns is wooden and brick historic buildings, detached houses, university complexes and new developments. If you are building a detached house yourself, Building Construction Regulations require electrical installation test documentation for acceptance into use. It is not a single sheet, but a measurement report, a protocol and a diagram describing what was built.

Measurements are done when the installation is finished and the distribution board assembled, but it is better to arrange the electrician while the wires are still visible. Then the routes can be photographed and later shown precisely in the as-built diagram. In Riga, putting into use is handled by the municipality’s City Development Department, and in cases started after 31 December 2019 the application is submitted in BIS.

If the electrical installation work was done by another electrician or a construction company, documentation can be prepared after the installation is finished too. Measurements take place on site, but for covered routes one has to rely on photos and what the installer can tell, so ask them to keep these.

For which other papers a self-built house needs, see the page self-built house: electrical documents for handover.

An old house in historic Pārdaugava without handover papers

Torņakalns is a historic Pārdaugava neighbourhood with university, railway and development areas. If you own an old house whose extensions were built without a building authority case or which has never been accepted into use, the electrical part can be described as it is now: site visit, as-built diagram, measurements and report.

For an old house it is useful to know the incoming supply: single-phase or three-phase and with which main protective device. If you plan electric heating or a heat pump, this shows whether the capacity at Sadales tīkls has to be dealt with together with the documents.

A concealed works record is not recreated after the work has been covered up; ask the building authority what it will accept instead. So before the electrical work, find out from the department which document package your house needs, and send us that list.

Temporary connection for a construction site: from permit to distribution board

Torņakalns has the railway, the Mārupīte stream and construction work in large development areas, and new buildings need electricity from the first day of construction. Sadales tīkls sets up a temporary connection for a construction site for the duration of the work, up to 24 months, and a valid building permit has to be attached to the application.

  1. Building permit A temporary connection for a construction site cannot be applied for without a valid building permit.
  2. Technical requirements Read the Sadales tīkls general technical requirements for a temporary connection.
  3. Construction site distribution board The electrician prepares the construction site board and connection point according to these requirements.
  4. Application The application is submitted to Sadales tīkls with the building permit attached.
  5. Permanent connection Plan the permanent connection in good time, because a temporary connection is for up to 24 months.

Checked on 25 November 2026: Sadales tīkls “Temporary connection”, section on a temporary connection for a construction site (sadalestikls.lv).

Once the house is built and the permanent connection set up, the construction site board is dismantled and electricity comes through the house incoming supply. This is also a suitable moment for the handover measurements, because the installation is finished and connected to its real supply.

For the steps of this service, see the page temporary connection for a construction site.

In your request, write the status of the BIS case, the planned duration of the work and which equipment will run on the site, such as a concrete mixer, crane or heaters. This determines what capacity and protection the construction site board needs.

An old and a new distribution board in one house: the as-built diagram

A detached house altered in stages may have an old board in the basement and a new board by the entrance, with some circuits still running through the old one. The as-built diagram, or wiring diagram, shows how everything is connected: from the incoming supply to each board and circuit. Without it the next electrician starts by tracing.

If the old board is no longer needed, the diagram also shows which circuits have to be moved to the new one before the old one can be dismantled. An electrician does this work, and afterwards the diagram is updated so that it matches reality.

In your request, write how many boards there are and where they are, and attach a photo. If there is an old design or drawing, attach that too. For this work, see the page as-built diagram.

Questions about these documents

For how long can a temporary connection for a construction site be set up?

Sadales tīkls sets up a temporary connection for a construction site for the duration of the work, up to 24 months. A valid building permit has to be attached to the application. A short-term connection for events is a different service with different conditions.

Does a self-built house in Riga need electrical documents at handover?

Yes. If a second-group residential house has been built by the owner, points 157.7.1 and 168.1 of Building Construction Regulations require electrical installation test documentation for acceptance. In Riga it is submitted to the City Development Department together with the other documents.

What to do if a house has both an old and a new distribution board?

First it has to be established which circuits run through which board. The as-built diagram made at the site visit shows this. Then both boards are checked in the measurements, and each is described separately in the report.
