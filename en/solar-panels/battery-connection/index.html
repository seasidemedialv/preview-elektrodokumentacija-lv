Connecting a battery to a microgenerator and the 11.1 kW limit

Since a battery is generating equipment, the total inverter capacity must stay within the microgenerator limits: 3.7 kW on a single-phase or 11.1 kW on a three-phase connection. If the battery inverter exceeds this limit, the system is no longer a microgenerator, and it is connected as a power station.

If you are in the old net metering, Sadales tīkls warns that changes to the connection or parameters can end participation. Check this before applying.

Connecting a hybrid inverter: what has to be signed

A hybrid inverter is allowed. Every inverter, including a hybrid one, needs its own inverter settings protocol. Sadales tīkls requires that the battery installation and inverter set-up are also carried out by a construction specialist with a certificate for generating equipment.

In the test we compare the inverter with the list approved by Sadales tīkls and check the protection settings and whether the general technical requirements are still met after the battery is added. These include a circuit breaker of up to 16 A between the inverter and the meter, disconnection without grid voltage. If the system is meant to have island mode, it needs synchronisation automation. Then we prepare a protocol for each inverter. Sadales tīkls may also ask for a calculation showing that the voltage rise up to the network boundary does not exceed 2 %, or 4.6 V.

Checked on 25 November 2026: Sadales tīkls, “Connecting a battery” and “General technical requirements for connecting a microgenerator” (sadalestikls.lv).

When a battery does not have to be approved

Sadales tīkls permission is needed for systems that run in parallel with the network. Off-grid systems not connected to the network do not need permission. If a battery with a hybrid inverter is connected to a house installation that is linked to the network, this is parallel operation, and an application is needed.

After permission the inverter settings must not be changed without the consent of Sadales tīkls. If you plan to change the battery or inverter settings, agree it with Sadales tīkls first.

Order of work

  1. Application On e-st.lv you request a parameter change or submit a new application.
  2. Installation A construction specialist with a certificate connects the battery and sets up the inverter.
  3. Test and protocol We test the system and prepare a protocol for each inverter.
  4. Confirmation You submit the confirmation with annexes; Sadales tīkls issues the permission.

For a microgenerator, Sadales tīkls issues permission within 3 working days of receiving the documents and may inspect the property before that. The deadlines are those of Sadales tīkls.

What to prepare

  • The battery and inverter model, power and capacity.
  • The permission for the existing microgenerator and the inverter data.
  • Information on whether you are in the old net metering.
  • Access to all inverters.

Questions: Connecting a battery to solar panels

Does a battery need Sadales tīkls permission?

Yes, if it runs in parallel with the network. Sadales tīkls treats a battery as generating equipment.

Is a hybrid inverter allowed?

Yes, Sadales tīkls allows a hybrid inverter. Like every other inverter, it needs its own settings protocol.

Can adding a battery end the old net metering?

Sadales tīkls warns that changes can end participation. Check this before applying.

Do you install batteries?

No. Installation is done by an installer; we test and prepare the papers for Sadales tīkls.

Does a battery without solar panels also have to be registered?

Yes. Sadales tīkls takes it as a new application in which the only source is the battery.
